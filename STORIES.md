# User Stories

## User Story 1: Add a book

As a reader
 I want to add a book to the catalog

### Acceptance Criteria

User can enter a book title and author.
User can save the book.
The new book appears in the catalog.
Empty titles and/or author cannot be saved.

## User Story 2: Add a book to favorite list

As a reader
 I want to add a book to my favorite list
 so that I can find it easier

### Acceptance Criteria

User can click on a book in the catalog.
Book is then marked in the catalog.
The new book appears in the favorite list.

## User Story 3: Remove a book to favorite list

As a reader
 I want to remove a book from my favorite list
 when I don't enjoy the book as much anymore

### Acceptance Criteria

User can click on a book in the catalog.
Book is then unmarked in the catalog.
The new book disappears in the favorite list.

## User Story 4: View favorite list

As a reader
 I want to see all books in my favorite list
 So that I can get an overview of what I plan to read.

### Acceptance Criteria

All saved books are displayed.
Books are shown in a clear list.
The list updates when books are added or removed.
